How it works

  1. Every {{ config.check_interval_seconds }}s the watchdog scans the allsky image directory.
  2. If no image is newer than {{ config.stale_threshold_seconds }}s, the camera is declared stale.
  3. The watchdog SSHs to the configured host and runs sudo systemctl restart {{ config.service_name }}.
  4. SSH credentials are stored encrypted. Configure them in Settings.
